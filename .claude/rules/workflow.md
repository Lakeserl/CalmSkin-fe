# Workflow & Quality Standards
- **Plan Mode:** Auto-enter for non-trivial tasks (3+ steps/architecture). Write detailed specs upfront; include verification steps.
- **Self-Improvement:** After any user correction, log lessons/rules into `tasks/lessons.md`. Review at session start.
- **Strict Verification:** Never mark complete without proof. Diff main vs changes. Run tests, check logs.
- **Elegance:** Pause and check for elegant solutions on non-trivial fixes. Avoid hacky code; do not overengineer obvious fixes.
- **Root Cause:** Find root causes, no temporary fixes. Minimal code impact.
